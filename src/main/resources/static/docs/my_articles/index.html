    Αποθηκευμένα άρθρα¶

    Στην ενότητα My Articles μπορείς να έχεις μια επισκόπηση όλων των άρθρων που είναι αποθηκευμένα στη δική σου βάση δεδομένων. Επιπλέον μπορείς να αναζητήσεις με βάση την κατηγορία τους ή/και μια λέξη-κλειδί.

    Πατώντας το κουμπί All Articles το σύνολο των άρθρων που βρίσκονται στη βάση, εμφανίζεται ανά κατηγορία.

    Μπορείς να ανοίξεις κάθε κατηγορία και να δεις τα άρθρα που ανήκουν σε αυτήν.

    Από εδώ, μπορείς να επεξεργαστείς τις πληροφορίες που έχεις αποθηκεύσει για ένα άρθρο, ή να το διαγράψεις, πατώντας Edit ή Delete, αντίστοιχα.

    Αναζήτηση στα αποθηκευμένα άρθρα¶

    Με το κουμπί Filters μπορείς να αναζητήσεις άρθρα στη βάση δεδομένων, με μια λέξη-κλειδί ή με την κατηγορία τους.

    Πατώντας Apply η σελίδα εμφανίζει μόνο τα άρθρα που αντιστοιχούν στην αναζήτηση.
